# Руководство аналитика: Insider Threat (Data Exfiltration)

## 1. Обнаружение (Detection)
Инциденты инсайдеров часто связаны с аномально большими объемами чтения данных с файловых серверов и их последующей архивацией.

**KQL для обнаружения запуска архиваторов с паролем (7z):**
```kql
event.code: "4688" AND process.name: "7z.exe" AND process.command_line: *-p*
```

**KQL для обнаружения выгрузки через системные утилиты (curl, wget, powershell):**
```kql
event.code: "4688" AND process.name: "curl.exe" AND process.command_line: *-F* AND process.command_line: *file=@*
```
