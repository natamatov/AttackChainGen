# Руководство аналитика: DCSync Attack

## 1. Обнаружение (Detection)
Атака DCSync имитирует поведение контроллера домена (DC) для запроса данных репликации через протокол DRSUAPI.

**KQL для поиска процессов, запрашивающих DCSync (Mimikatz):**
```kql
event.code: "4688" AND process.command_line: *dcsync*
```

**KQL для поиска подозрительного трафика к DC (RPC/135):**
*(Обычно репликацию могут запрашивать только другие DC, IP-адреса которых известны: 192.168.100.2, 192.168.100.3)*
```kql
event.code: "3" AND destination.ip: ("192.168.100.2" OR "192.168.100.3") AND NOT source.ip: ("192.168.100.2" OR "192.168.100.3") AND destination.port: "135"
```

# Чеклист расследования

## Артефакты
- [ ] Учетная запись, выполнявшая DCSync (должна обладать правами Replicating Directory Changes).
- [ ] Имя хоста, с которого инициирован запрос (PC-DIRECTOR).
- [ ] Инструмент, использованный для атаки (Mimikatz / Impacket).

## Действия
- [ ] Заблокировать скомпрометированную УЗ (administrator).
- [ ] Проверить все сетевые входы (4624) от скомпрометированной УЗ после момента атаки (Lateral Movement).
- [ ] Очистить хост атакующего (PC-DIRECTOR).
- [ ] Сбросить пароль KRBTGT дважды (чтобы инвалидировать Golden Tickets).
