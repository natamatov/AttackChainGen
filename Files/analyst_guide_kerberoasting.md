# Руководство аналитика: Kerberoasting Attack

## 1. Обнаружение (Detection)
Атака Kerberoasting направлена на получение билетов TGS (Ticket Granting Service) для аккаунтов служб (SPN) с целью их офлайн-взлома.

**KQL для обнаружения запуска инструментов:**
```kql
event.code: "4688" AND process.name: "Rubeus.exe" AND process.command_line: *kerberoast*
```

**KQL для обнаружения подозрительного трафика к DC (Port 88):**
*(В сочетании с появлением новых файлов, содержащих хеши)*
```kql
event.code: "3" AND destination.port: "88" AND process.name: "Rubeus.exe"
```
```kql
event.code: "11" AND file.name: "hashes.txt"
```

# Чеклист расследования

## Артефакты
- [ ] Инструмент, использованный для атаки (Rubeus.exe).
- [ ] Имя хоста-инициатора атаки (PC3).
- [ ] Какие Service Principal Names (SPN) были запрошены (обычно видно в Event ID 4769 на контроллере домена).

## Действия
- [ ] Сбросить пароли для скомпрометированных сервисных учетных записей.
- [ ] Убедиться, что для сервисных УЗ включен атрибут "AES256" или более стойкое шифрование (запрет RC4).
- [ ] Изолировать PC3 и проверить, как хакер получил к нему доступ.
