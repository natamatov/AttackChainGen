# Analyst Playbook: External Recon & Web Exploitation (T1595, T1190)

## Описание атаки
Этот сценарий симулирует действия внешнего злоумышленника, который сканирует публично доступный почтовый сервер (`mail01`), находит уязвимость (например, ProxyShell в MS Exchange) и эксплуатирует её для получения первичного доступа (Initial Access).

## Затронутые активы
- **Цель:** `mail01` (192.168.100.5)
- **Тактики:** Reconnaissance, Initial Access
- **Техники:** T1595 (Active Scanning), T1190 (Exploit Public-Facing Application)

## Чеклист расследования
1. [ ] **Сетевой анализ:** Найдите сетевые соединения на порт 443 сервера `192.168.100.5` с внешнего IP-адреса.
2. [ ] **Анализ Web-логов (IIS):** Проверьте логи IIS на наличие сканирующих запросов или аномальных URI, таких как `/autodiscover/autodiscover.json`.
3. [ ] **Анализ процессов (Sysmon):** Найдите события создания процессов (Sysmon Event ID 1), где родителем выступает рабочий процесс веб-сервера (`w3wp.exe`), а дочерним — командный интерпретатор (`cmd.exe` или `powershell.exe`).
4. [ ] **Реагирование:** 
    - Изолируйте скомпрометированный сервер `mail01`.
    - Заблокируйте IP-адрес атакующего на NGFW.
    - Установите патчи безопасности для MS Exchange/IIS.
