# Руководство аналитика: Phishing Attack с Латеральным Перемещением

## 1. Первичный вектор компрометации (Initial Access)
**Сценарий:** Пользователь `jdoe` на рабочей станции `PC1` получил письмо с вредоносным вложением `invoice_2026.doc.exe`. Вложение было сохранено на диск и запущено пользователем через почтовый клиент (Outlook).

**KQL-запросы для Kibana:**
*Обнаружение создания подозрительного файла в папке Downloads (Sysmon Event ID 11):*
```kql
event.code: "11" AND file.name: "*.exe" AND file.path: *Downloads* AND host.name: "PC1"
```
*Обнаружение запуска подозрительного файла из почтового клиента (WinEvent ID 4688):*
```kql
event.code: "4688" AND process.parent.name: "outlook.exe" AND process.name: "*.exe"
```

## 2. Закрепление и C2 (Execution & C&C)
После запуска вредонос устанавливает сетевое соединение с C2-сервером для получения команд.

**KQL-запросы для Kibana:**
*Поиск внешних сетевых подключений от сомнительного бинарника (Sysmon Event ID 3):*
```kql
event.code: "3" AND process.name: "invoice_2026.doc.exe" AND destination.port: "443"
```
*Ожидаемый результат:* Соединение с `192.168.100.254` (или другим внешним IP) от зараженного хоста.

## 3. Разведка (Discovery)
Малварь или злоумышленник собирает информацию о зараженной системе.

**KQL-запросы для Kibana:**
*Запуск утилит разведки из-под подозрительного родительского процесса:*
```kql
event.code: ("1" OR "4688") AND process.name: "whoami.exe" AND process.parent.name: "invoice_2026.doc.exe"
```

## 4. Латеральное перемещение (Lateral Movement)
Собрав учетные данные, атакующий пытается получить доступ к критичной инфраструктуре (Domain Controller `AD02`).

**KQL-запросы для Kibana:**
*Успешный сетевой вход на контроллер домена (Logon Type 3):*
```kql
event.code: "4624" AND winlog.logon.type: "3" AND source.ip: "192.168.100.20" AND host.name: "AD02"
```

## 5. Воздействие (Impact)
Получив доступ к `AD02`, атакующий пытается сдампить базу данных Active Directory (NTDS.dit).

**KQL-запросы для Kibana:**
*Использование ntdsutil.exe для дампа AD:*
```kql
event.code: ("1" OR "4688") AND host.name: "AD02" AND process.command_line: *ntdsutil* AND process.command_line: *ifm*
```

# Чеклист расследования

## 1. Сбор артефактов (Artifacts Collection)
- [ ] Имя вредоносного файла и полный путь на диске (`invoice_2026.doc.exe`)
- [ ] SHA256 хеш вредоносного файла (из Sysmon Event 1 или 11)
- [ ] IP-адрес и порт C2-сервера (Destination IP/Port из Sysmon 3)
- [ ] Скомпрометированная учетная запись (Target User)

## 2. Анализ цепочки атаки (Kill Chain Analysis)
- [ ] Выявлен ли факт успешной доставки и запуска фишингового файла?
- [ ] Зафиксировано ли исходящее соединение к C2-серверу?
- [ ] Какие команды разведки (whoami, net, ipconfig) были выполнены?
- [ ] Подтверждено ли латеральное перемещение на другие хосты (особенно AD02)?
- [ ] Зафиксированы ли попытки дампа кредов (NTDS, LSASS) на контроллере домена?

## 3. Меры по реагированию (Incident Response)
- [ ] **Изоляция:** Немедленно отключить `PC1` (192.168.100.20) от сети.
- [ ] **Блокировка:** Добавить IP C2-сервера (`192.168.100.254`) в block-list на NGFW.
- [ ] **Сброс паролей:** Сбросить пароль пользователя `jdoe` и, что более критично, `administrator`.
- [ ] **Удаление малвари:** Удалить вредоносный файл из папки Downloads на `PC1`.
- [ ] **Проверка AD:** Проверить, не были ли созданы новые административные учетные записи на `AD02` за время присутствия злоумышленника.
