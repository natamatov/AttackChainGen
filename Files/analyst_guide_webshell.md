# Руководство аналитика: Web Server Exploitation & Web Shell

## 1. Обнаружение (Detection)
Скомпрометированные веб-серверы обычно начинают вести себя нетипично — создавать файлы в веб-директориях или запускать системные процессы.

**KQL для обнаружения запуска cmd.exe или powershell.exe из-под веб-сервера (IIS):**
```kql
event.code: "4688" AND process.parent.name: "w3wp.exe" AND process.name: ("cmd.exe" OR "powershell.exe")
```

**KQL для обнаружения создания скриптов веб-шеллов:**
```kql
event.code: "11" AND file.path: *inetpub\\wwwroot* AND file.name: (*.aspx OR *.php OR *.jsp)
```

**KQL для обнаружения аномальных исходящих соединений (Reverse Shell):**
```kql
event.code: "3" AND process.name: ("powershell.exe" OR "cmd.exe") AND source.ip: "192.168.100.5"
```
