# Analyst Playbook: Registry Persistence & Account Backdoor (T1098, T1547.001)

## Описание атаки
Этот сценарий описывает процесс долгосрочного закрепления (Persistence) злоумышленника на файловом сервере `FS01`. Атакующий создает теневую учетную запись локального администратора и прописывает автозагрузку вредоносного файла через ключи реестра (Run keys).

## Затронутые активы
- **Цель:** `FS01` (192.168.100.1)
- **Тактики:** Persistence
- **Техники:** T1098 (Account Manipulation), T1547.001 (Boot or Logon Autostart Execution)

## Чеклист расследования
1. [ ] **Управление учетными записями:** Найдите события создания пользователя (Event ID 4720) на сервере `FS01`.
2. [ ] **Изменение групп:** Проверьте события добавления пользователя в привилегированные группы (Event ID 4732).
3. [ ] **Мониторинг реестра (Sysmon):** Найдите события модификации реестра (Sysmon Event ID 12 или 13) для ветки `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`.
4. [ ] **Реагирование:** 
    - Удалите несанкционированную учетную запись.
    - Удалите вредоносный ключ реестра и исполняемый файл.
    - Проведите аудит паролей всех локальных администраторов.
