# Analyst Playbook: WMI Remote Execution (T1047)

## Описание атаки
Этот сценарий симулирует латеральное перемещение и удаленное выполнение кода с помощью встроенного инструмента WMI (Windows Management Instrumentation). Атакующий использует WMI на `PC1` для незаметного запуска процессов на `PC2`.

## Затронутые активы
- **Цель:** `PC2` (192.168.100.21)
- **Источник:** `PC1` (192.168.100.20)
- **Тактики:** Execution
- **Техники:** T1047 (Windows Management Instrumentation)

## Чеклист расследования
1. [ ] **Сетевой анализ:** Проверьте сетевые подключения на порт 135 (RPC/WMI) между рабочими станциями `PC1` и `PC2`.
2. [ ] **Анализ процессов (Sysmon/Security):** Найдите события создания процессов (Event ID 4688 или Sysmon 1) на `PC2`, где родительским процессом является `WmiPrvSE.exe`.
3. [ ] **Аномалии WMI:** Проверьте журналы Microsoft-Windows-WMI-Activity/Operational на наличие ошибок или подозрительных клиентских подключений (ClientProcessId).
4. [ ] **Реагирование:** 
    - Изолируйте хосты `PC1` и `PC2`.
    - Ограничьте использование WMI между рабочими станциями на уровне хостового файрвола.
