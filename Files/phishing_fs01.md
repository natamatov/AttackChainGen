# Analyst Guide: Phishing & Lateral Movement to FS01

## 1. Overview
Этот сценарий описывает цепочку атаки, начинающуюся с успешной фишинговой рассылки на машину сотрудника бухгалтерии (**PC-Accountant**). После запуска вредоносного вложения злоумышленник выполняет сетевое сканирование (Recon) для поиска критичных активов и осуществляет боковое перемещение (Lateral Movement) на файловый сервер **FS01** через протокол SMB.

## 2. Detection & Triage

### Идентификация первоначального доступа
Ищите запуск подозрительных процессов (двойные расширения, запуск из папки Downloads), родителем которых является почтовый клиент (например, Outlook).

**KQL запрос (Kibana / Elastic):**
```kql
winlog.event_id: "4688" 
  AND process.parent.name: "OUTLOOK.EXE" 
  AND process.name: *.exe 
  AND process.working_directory: *Downloads*
```

### Выявление разведки сети (Recon)
Поиск сетевых подключений по протоколу SMB (порт 445) от необычных процессов.

**KQL запрос (Kibana / Elastic):**
```kql
winlog.channel: "Microsoft-Windows-Sysmon/Operational"
  AND winlog.event_id: "3"
  AND destination.port: "445"
  AND NOT process.name: ("System" OR "svchost.exe")
```

### Обнаружение бокового перемещения
Мониторинг успешных сетевых входов (Logon Type 3) на критичные серверы (FS01) с пользовательских рабочих станций.

**KQL запрос (Kibana / Elastic):**
```kql
winlog.event_id: "4624"
  AND winlog.event_data.LogonType: "3"
  AND host.hostname: "FS01"
  AND winlog.event_data.IpAddress: "192.168.100.23"
```

## 3. Investigation Steps

### Шаг 1: Анализ PC-Accountant (192.168.100.23)
*   Найдите событие 4688 и подтвердите запуск файла `Invoice.pdf.exe`.
*   Извлеките хэш файла (если логируется Sysmon Event ID 1) и проверьте его по базам VirusTotal/Threat Intelligence.
*   Изолируйте машину от корпоративной сети для предотвращения дальнейшего распространения ВПО.

### Шаг 2: Анализ сетевой активности
*   Проверьте Sysmon Event ID 3 на `PC-Accountant`. Были ли попытки подключения к другим серверам, помимо `FS01`?
*   Проанализируйте логи Firewall/NGFW (`FORTIGATE1`, `FORTIGATE2`), чтобы выявить попытки связи с внешними C2-серверами.

### Шаг 3: Анализ FS01 (192.168.100.1)
*   Проверьте логи безопасности на `FS01` на предмет доступа к общим папкам или создания новых подозрительных служб (Event ID 7045 / 4697).
*   Проверьте, какие файлы были изменены или скачаны учетной записью `accountant` на сервере.

## 4. Containment & Remediation
*   **Изоляция ПК:** Немедленно отключите `PC-Accountant` от сети.
*   **Сброс УЗ:** Принудительно сбросьте пароль учетной записи `accountant@corp.local.uz`.
*   **Удаление ВПО:** Удалите файл `Invoice.pdf.exe` со всех устройств в сети с помощью EDR/Антивируса.
*   **Защита почты:** Добавьте отправителя фишингового письма в черный список на шлюзе `mail01` и удалите письмо из всех почтовых ящиков.

# Investigation Checklist

## Triage
- [ ] Подтвержден запуск подозрительного файла из Outlook на `PC-Accountant`.
- [ ] Выявлены попытки сетевого сканирования порта 445 (SMB) с `PC-Accountant`.
- [ ] Зафиксирован успешный сетевой вход на файловый сервер `FS01` под УЗ `accountant`.

## Analysis
- [ ] Собран хэш вредоносного файла `Invoice.pdf.exe`.
- [ ] Проведен аудит всех сетевых соединений от процесса `Invoice.pdf.exe`.
- [ ] Проверен файловый сервер `FS01` на наличие измененных или эксфильтрованных данных.
- [ ] Выявлен источник фишингового письма (Email отправителя, IP, заголовки).

## Containment & Remediation
- [ ] Хост `PC-Accountant` изолирован.
- [ ] Пароль пользователя `accountant` сброшен.
- [ ] Письмо удалено с сервера `mail01` (Search & Destroy).
- [ ] Хэш файла добавлен в черный список EDR (IOC Sweep).
- [ ] Инцидент задокументирован.
