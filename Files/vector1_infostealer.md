# Analyst Guide: Vector 1 - AI-Enhanced Phishing & InfoStealer

## 1. Overview
В данном сценарии имитируется атака с использованием высококачественного фишингового письма, которое обходит спам-фильтры. Пользователь (бухгалтер) запускает вредоносный файл `setup.exe`, который сбрасывает полезную нагрузку (`payload.dll`) и связывается с Telegram API (149.154.167.220) для выгрузки украденных сессионных cookie-файлов и сохранённых паролей браузера.

## 2. Detection & Triage

### KQL: Запуск процесса из Outlook
Ищем процессы, запущенные из почтового клиента из подозрительных директорий (Downloads, Temp).
```kql
winlog.event_id: "4688" 
  AND process.parent.name: "OUTLOOK.EXE" 
  AND process.name: "setup.exe"
```

### KQL: Создание DLL в профиле пользователя
Ищем сброс исполняемых файлов (DLL/EXE) в папке AppData (Sysmon Event ID 11).
```kql
winlog.channel: "Microsoft-Windows-Sysmon/Operational"
  AND winlog.event_id: "11"
  AND file.path: *AppData\\Roaming\\*.dll
```

### KQL: Сетевое соединение с C2 (Telegram API)
Мониторинг исходящего трафика от недоверенных процессов в сторону IP-адресов мессенджеров.
```kql
winlog.channel: "Microsoft-Windows-Sysmon/Operational"
  AND winlog.event_id: "3"
  AND destination.ip: "149.154.167.220"
```

## 3. Investigation Steps

1. **Анализ рабочей станции PC-Accountant (192.168.100.23):** 
   - Найдите письмо в почтовом ящике `accountant` и извлеките заголовки для выявления отправителя.
   - Извлеките файл `setup.exe` и `payload.dll` для проведения реверс-инжиниринга.
2. **Оценка ущерба:**
   - Выясните, к каким корпоративным системам был доступ у пользователя. Так как это стилер, злоумышленники могли украсть сессии от VPN, Office 365, или внутренних порталов.

## 4. Containment & Remediation
- Немедленно сбросьте все активные сессии пользователя `accountant` во всех SaaS и внутренних сервисах.
- Смените пароль пользователя.
- Заблокируйте IP 149.154.167.220 на межсетевом экране (FORTIGATE), если легитимное использование Telegram запрещено.

# Investigation Checklist

- [ ] Письмо-источник найдено в почтовом ящике.
- [ ] IOC (хэши `setup.exe` и `payload.dll`) добавлены в EDR для блокировки.
- [ ] Сетевой трафик к C2 заблокирован на NGFW.
- [ ] Все сессии пользователя-жертвы аннулированы (сброс пароля + отзыв токенов).
- [ ] Хост `PC-Accountant` изолирован для криминалистической копии.
